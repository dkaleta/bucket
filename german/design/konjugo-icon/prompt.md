# KonjuGo app icon

Generated using the built-in image generation tool. The source PNG preserves transparency; macOS asset sizes are exported with `sips`.

## Prompt

Use case: logo-brand
Asset type: production macOS application icon for KonjuGo, a focused German verb conjugation learning app.
Primary request: Create one beautiful, polished native Mac app icon. A bold sculptural uppercase K, like a letter assembled from three beautifully crafted pieces, on a deep midnight ink rounded-square tile. The upright and upper diagonal of the K are warm ivory; the lower diagonal is vivid tangerine orange, suggesting a verb ending that changes. The K must read instantly at tiny Dock sizes. This is the only letter.
Style: restrained premium three-dimensional icon design, softly beveled ceramic-like surfaces, very subtle dimensional shadows, crisp silhouette, elegant and friendly. Straight-on view, no perspective tilt. The orange accent relates to the app's orange irregular-conjugation highlights.
Composition: square 1024 by 1024 canvas; centered rounded-square macOS tile approximately 840 by 840 pixels with generous continuous rounded corners. Bold K centered inside with balanced padding. Actual transparent alpha background outside the tile including the canvas corners; subtle soft shadow immediately under the tile. The icon fills the intended tile; no outer frame.
Constraints: one icon only, no mockup, no desktop, no extra symbols, no flags, no caption, no words, no watermark, no tiny detail, no checkerboard painted into image. Genuine transparency outside tile.
